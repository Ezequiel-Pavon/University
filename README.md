# Ingeniería Mecánica ⚙️

Repositorio personal con apuntes, ejercicios, trabajos prácticos, proyectos y material de estudio correspondiente a mi segunda carrera: **Ingeniería Mecánica**.

La idea de este repositorio es centralizar y organizar todo el contenido académico de la carrera, facilitando tanto el estudio cotidiano como la consulta posterior de conceptos, resoluciones y proyectos.

## Objetivos

Este repositorio tiene como objetivos:

1. Centralizar el material de estudio de Ingeniería Mecánica.
2. Mantener una organización clara de las materias.
3. Registrar ejercicios y problemas resueltos.
4. Documentar proyectos y trabajos prácticos.
5. Construir una biblioteca personal de consulta.
6. Registrar el aprendizaje de herramientas utilizadas en ingeniería.
7. Desarrollar progresivamente un portfolio técnico.
